01En producción

Hoja Diaria Renal

Aplicación web para el registro diario de sesiones de hemodiálisis en una unidad renal. Reemplaza la planilla de papel y Excel.

  • Sesión diaria por turno con 3 estaciones de 16 camas (48 puestos) y guardado automático.
  • Cálculos automáticos de pérdida de peso y ganancia interdialítica, con alertas.
  • Programación mensual de EPO y hierro, y cierre del día imprimible.
  • Asistente con IA, CI con pruebas automatizadas y datos 100% ficticios.

Nació de mi experiencia en el sector salud: conozco el problema de primera mano.

Tecnologías

  • Python
  • FastAPI
  • SQLAlchemy
  • PostgreSQL (Neon)
  • Tailwind CSS
  • IA (Claude API)
  • Docker
  • GitHub Actions
  • Render

02Desplegado en Vercel

Fusion D'Lauris

Tienda de café especial y cursos: el cliente arma su pedido en la web y la venta se cierra por WhatsApp.

  • Monorepo con frontend React y API NestJS en un solo proyecto de Vercel.
  • Cada pedido crea o actualiza al cliente en PostgreSQL (Supabase) con códigos FD-1001…
  • Panel /admin con estados del pedido, de cotizado a entregado.
  • Bot de WhatsApp gratuito basado en reglas sobre el catálogo, y respaldo si la API falla: no se pierde la venta.

Tecnologías

  • React
  • TypeScript
  • Vite
  • NestJS
  • Node.js
  • PostgreSQL (Supabase)
  • Vercel
  • WhatsApp Cloud API

03En producción

Mi Día PWA

App web progresiva de hábitos diarios (gym, alimentación, sueño, agua, oración). Se instala en Android y funciona sin internet.

  • Instalable con manifest y service worker, 100% offline.
  • Cuentas locales con contraseña con hash y salt (Web Crypto API).
  • Modo claro y oscuro automático.
  • Exportar e importar tus datos.

Tecnologías

  • HTML5
  • CSS3
  • PWA
  • Service Worker
  • Web Crypto API
  • localStorage
